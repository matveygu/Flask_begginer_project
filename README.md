# Flask Project

Простое веб-приложение на **Flask**, сделанное для проверки сил и знакомства с фреймворком.  
Сайт развернут на PythonAnywhere и доступен по адресу: https://flask-begginer-project.onrender.com

## 📌 Описание

Этот проект представляет собой учебный веб-сайт, созданный с целью:

- практики в разработке на Python и Flask;
- знакомства с маршрутизацией, шаблонами и статическими ресурсами;
- деплоя на PythonAnywhere.

Сайт содержит простые страницы с информацией и демонстрирует базовый функционал, включающий HTML-шаблоны, CSS/JS и структуру Flask-приложения.

## 🚀 Стек технологий

Проект построен с использованием:

- Python  
- Flask
- HTML / CSS / JS

## 🛠️ Как запустить локально

1. **Клонируй репозиторий:**
   ```bash
   git clone https://github.com/matveygu/siteproject.git
   cd siteproject
   ```

2. **Создай виртуальное окружение и активируй его:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate   # Linux / macOS
   venv\Scripts\activate      # Windows
   ```

3. **Установи зависимости:**
   ```bash
   pip install flask
   ```

4. **Запусти приложение:**
   ```bash
   python app.py
   ```

5. Открой в браузере:
   ```
   http://127.0.0.1:5000
   ```
